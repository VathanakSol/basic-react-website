# React Basic Website

A basic website built with **React.js** (React 18 + Babel standalone). No build step required — it runs directly in the browser.

## Run locally

### Option 1 — Open directly
Just open `index.html` in your browser. That's it.

### Option 2 — Local server (recommended)
```bash
npx serve .
```
Then visit http://localhost:3000

## Structure
```
├── index.html      # Entry point (loads React via CDN)
├── src/
│   ├── App.jsx     # Main React component (nav, hero, features, about, contact, footer)
│   └── index.css   # Styles
├── package.json
└── README.md
```

## Features
- Responsive navbar
- Hero section
- Feature cards
- About section
- Contact form (client-side demo)
- Footer

Built with plain React components — no framework or bundler needed.
